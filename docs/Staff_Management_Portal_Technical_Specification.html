1. Project Overview & Core Capabilities

The Staff Management Portal is a high-performance enterprise employee administration and organizational workforce platform. Built with a clean separation of concerns, the system enables corporate administrators to register their organization, establish an isolated company workspace, and manage employee records throughout their entire employment lifecycle.

1.1 Architectural Pillars

  • Strict Admin Tenancy (1 Admin = 1 Company = All Employees): Each unique email registration establishes an independent Administrator account. Every administrator owns exactly one company workspace, and all employee records belong exclusively to that company. Strict backend ownership checks prevent cross-tenant data leakage.
  • Dual-Provider Secure Authentication: Integrated support for email/password registration backed by 6-digit cryptographic OTP delivery, along with Google OAuth 2.0 / OpenID Connect Single Sign-On (SSO). Both authentication flows automatically provision authenticated accounts with the ADMIN role.
  • Full-Lifecycle Employee CRUD: Comprehensive employee management supporting creation, profile viewing, multi-attribute updates, salary adjustment, department reassignment, and safe record deletion with confirmation modals.
  • Real-Time Workforce Analytics & Telemetry: Instant telemetry on total employee headcount, active company departments, overall payroll expenditure, average salary benchmarks, and department staff distribution.
  • Continuous Availability & Keep-Alive Diagnostics: Dedicated public /api/health endpoint returning service status and ISO timestamps, optimized for continuous cloud monitoring via UptimeRobot to eliminate cold-start delays on cloud containers.
  • Interactive Swagger / OpenAPI 3.0 Documentation: Native interactive API explorer supporting live execution and Bearer JWT authorization testing.

4. Role-Based Access Control (RBAC) & Tenancy Isolation

The application follows an Admin-Only Single-Tenant Workspace Architecture. All end-users interacting with the portal are Administrators who manage their respective organizational silos. Regular employees do not log into the administrative portal, guaranteeing that privileged payroll and personnel data remain confidential.

6. Security, Authentication & Cryptography

  • Password Hashing: Passwords are salted and hashed using Spring Security's BCryptPasswordEncoder with a standard strength factor of 10. Passwords are never stored or logged in plaintext.
  • Stateless JWT Issuance: Signed using HMAC-SHA256 (256-bit secret key). Tokens encapsulate subject ID, authenticated email, and the ADMIN authority claim with a configurable expiration duration (default 24 hours).
  • CORS & CSRF Defense: Cross-Origin Resource Sharing is enabled with explicit whitelist allowances for HTTP methods (GET, POST, PUT, DELETE, OPTIONS) and request headers. CSRF protection is safely disabled as the backend uses stateless JWT authentication with no session cookies.
  • Automatic Legacy Role Migration: The AccountRoleMigrationRunner component executes on every Spring Boot startup, seamlessly upgrading any legacy user records to the ADMIN role while preserving all existing company links and employee records.

7. Live Cloud Deployment & Continuous Availability (UptimeRobot)

Continuous Uptime Architecture: Free-tier cloud instances (e.g. Render, Railway) suspend compute containers after 15 minutes of inactivity. The integrated /api/health endpoint is designed to receive automated HTTP GET probes from UptimeRobot every 5 minutes, keeping the container warm and eliminating latency spikes for end-users.
